# Contributing

Thanks for your interest in MetaSleuth.

## Before contributing

1. Open an issue describing the bug or proposed improvement.
2. Avoid including private, personal, or confidential evidence in issues.
3. Keep changes focused and document any new dependencies.
4. Test changes on the supported Windows/Python versions.

## Pull requests

- Explain the problem and the solution.
- Include reproducible test steps.
- Update the README or changelog when behavior changes.
- Never commit credentials, private evidence, generated reports, or local configuration.

The project owner reviews and decides whether contributions are accepted.
