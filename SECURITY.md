# Security Policy

## Supported versions

Security reports should identify the affected MetaSleuth version or commit.

## Reporting a vulnerability

Please do not publish exploitable details, private evidence, or sensitive files in a public issue. Contact the repository owner privately through a contact method listed on the owner's GitHub profile.

Include:
- affected version/commit;
- a concise description and impact;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation.

Do not submit real personal data or third-party evidence.
